# AutoDev Tools 2026

### The legacy returns. A new era of Android modding.

**AutoDev Tools 2026** é um projeto de revitalização desktop inspirado no clássico **AutoDev Tools 2015**, originalmente desenvolvido por Raphael Batista Fontão (RBF Studio Inc).

Uma homenagem à ferramenta original, reconstruída com uma experiência desktop moderna e uma nova abordagem para o trabalho com APKs.

---

##  Aplicativo

O aplicativo desktop nativo é a experiência principal do AutoDev Tools 2026.

Para iniciar, execute:

`AutoDevTools2026.exe`

###  APK Lab

O APK Lab é o espaço de trabalho para analisar e decompilar arquivos APK.

**Como utilizar:**

1. Arraste um arquivo `.apk` para o APK Lab ou clique em **Buscar APK**.
2. O aplicativo preencherá automaticamente o caminho do APK.
3. Uma pasta de saída será definida automaticamente no formato `workspace<nome-do-apk>_decompiled`.
4. Clique em **Decompilar**.
5. O Apktool será utilizado para realizar o processo.

Simples, direto e sem precisar enfrentar um terminal cheio de comandos.

---

##  Requisitos

Antes de executar o aplicativo, verifique se você possui:

- Windows.
- **Java instalado** e configurado.
- Um conjunto de ferramentas compatível com o AutoDev Tools 2026.

###  Configuração das ferramentas

Esta versão ainda não é independente. Ela precisa de ferramentas externas compatíveis, fornecidas por uma das seguintes alternativas:

- Variável de ambiente `AUTODEV_TOOL_HOME`.
- Pasta local `tools`.
- Como alternativa legada, uma instalação do **AutoDev Tools 2015**.

> **IMPORTANTE:** O Java é obrigatório. Sem ele, determinadas operações poderão não funcionar.
